# Historical FIM workflow material

This directory contains migration evidence only. It is not a session-start
location or an operating manual. Start substantive FIM work through the
repository-root `AGENTS.md` or `CLAUDE.md`, run the required preflight, and use
`origin/workflow/shared-context` or an owned task branch from it.

Historical instructions are retained here to explain earlier decisions, not to
route a new task to a legacy checkout, workbench, or branch.
